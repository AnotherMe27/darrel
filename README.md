# Wallace Ganda Portfolio

A responsive personal portfolio for CSN 1101 Assignment One. The home page introduces Wallace, shares his interests and current learning goals, and provides direct contact links.

## Built With

- Next.js and React
- Semantic JSX sections: `header`, `nav`, `main`, and `footer`
- External CSS with responsive media queries for phone and desktop layouts

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in a browser. Create a production build with `npm run build`.
